### HƯỚNG DẪN MỞ & XUẤT ẢNH DÁN VÀO ĐỒ ÁN TỐT NGHIỆP:

1. **Cách 1 - Mở bằng Visual Studio Code (Nhanh nhất):**
   - Cài đặt extension: **Draw.io Integration** (tác giả Henning Dieterichs).
   - Click đúp trực tiếp vào bất kỳ file `.drawio` nào trong thư mục này để xem và chỉnh sửa trực quan.
2. **Cách 2 - Mở qua trình duyệt web:**
   - Truy cập trang web: [https://app.diagrams.net/](https://app.diagrams.net/).
   - Chọn **Open Existing Diagram** &rarr; Chọn file `.drawio` tương ứng từ máy tính.
3. **Cách xuất ảnh dán vào file Word / LaTeX báo cáo:**
   - Trong Draw.io, chọn menu: **File** &rarr; **Export as** &rarr; **PNG...** (hoặc **SVG...** để có độ sắc nét véc-tơ cao nhất khi in ấn).
   - Chọn độ phân giải: **300 DPI** hoặc chọn phóng to **200%** để hình ảnh khi in ra khổ giấy A4 không bị mờ vỡ nét.
